3. - git init: perintah yang digunakan untuk membuat/menginisialisasi repository git baru di dalam folder proyek.
- git clone: perintah yang digunakan untuk menyalin repository yang sudah ada dari remote server ke komputer lokal.
- git remote: perintah yang digunakan untuk melihat, menambahkan, atau menghapus remote repository (lokasi penyimpanan proyek) yang terhubung dengan repository lokal.
- git add: perintah yang digunakan untuk menambahkan file yang telah diubah atau baru dibuat ke dalam staging area (tempat sementara) sebelum dilakukan commit.
- git commit: perintah yang digunakan untuk menyimpan perubahan yang sudah ditambahkan ke dalam repository secara permanen.
- git push: perintah yang digunakan untuk mengirim/mengunggah perubahan dari repository lokal ke remote repository.
- git checkout: perintah yang digunakan untuk berpindah ke branch lain atau mengembalikan file ke kondisi/versi tertentu dari riwayat git.

5. Variabel user adalah variabel lingkungan yang ditetapkan untuk setiap pengguna, sedangkan variabel system adalah variabel lingkungan yang ditetapkan untuk semua pengguna. 

sedangkan

Variabel sistem adalah komponen atau parameter dalam suatu sistem yang digunakan untuk menggambarkan, mengontrol, atau memengaruhi perilaku sistem tersebut. Variabel ini bisa berupa input, output, atau variabel internal yang memengaruhi dinamika sistem.

Perbedaan variabel user dan variabel system:
Variabel user ditetapkan untuk setiap pengguna, sedangkan variabel system ditetapkan untuk semua pengguna. 
Jalur pengguna tidak memungkinkan untuk mengganti jalur sistem. 
Jalur sistem dicari secara berurutan, dari kiri ke kanan, dan jalur pengguna ditambahkan di sisi kanan.
